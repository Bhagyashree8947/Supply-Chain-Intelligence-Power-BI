# 🚚 Supply Chain Intelligence Dashboard

## 📊 Project Overview

From raw operational data to strategic business insights.

This interactive Power BI dashboard provides an end-to-end view of supply chain performance across orders, demand, inventory, profitability, logistics, transportation, and delivery operations.

The project uses data modeling, DAX measures, KPI analysis, and interactive visualizations to identify performance trends, operational bottlenecks, delivery delays, inventory opportunities, and regional patterns that support data-driven decision-making.

## 🎯 Business Objectives

- Monitor overall supply chain performance
- Analyze order volume and customer demand
- Evaluate inventory and product performance
- Track profitability and sales performance
- Measure delivery and service-level performance
- Analyze transportation costs by transport mode
- Identify regional and country-level performance
- Detect potential operational inefficiencies

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Modeling
- Power Query
- Data Visualization
- KPI Analysis
- Supply Chain Analytics

## 📌 Key KPIs

- Order Volume
- Gross Sales
- Total Profit
- Total Units Sold
- Inventory / Current Stock
- Customer Demand
- On-Time Delivery Rate
- In-Full Delivery Rate
- Delivery Delay
- Transportation Cost
- Revenue per Order
